<h1>🔢 Number Formatter</h1>
<p>
  A simple number formatter that converts large numbers into shorter,
  more readable values using abbreviations.
</p>
<h2>✨ Features</h2>
<ul>
  <li>🔢 Formats large numbers using abbreviations.</li>
  <li>📈 Supports values from thousands to extremely large numbers.</li>
  <li>🔤 Uses abbreviations such as <code>K</code>, <code>M</code>, <code>B</code>, <code>T</code> and more.</li>
  <li>🎨 Simple and clean user interface.</li>
  <li>⚡ Displays results as you enter a number.</li>
</ul>
